# Demo walkthrough

1. Run `pnpm dev` and open http://localhost:3000. Start with the death-over challenge: 178/5 after 18 overs, chasing 201, with 23 required from 12 balls. Read the replay/illustrative labels.
2. Compare bowling options and their eligibility. Select an available bowler; unavailable options explain their overs or consecutive-over restriction.
3. Apply a field preset. Drag a fielder to a free named position, then try the mobile-friendly select-and-tap method. Undo the change. Review the inside/outside count and legality feedback.
4. Choose a bowling intention and add a brief explanation. Lock the call. The selected field and bowler are preserved.
5. Read the combined tactical assessment, strengths, vulnerabilities, field support, suggested adjustments, and assumptions. With no API key, point out the **Demo analysis** label.
6. Inspect the seeded illustrative baseline runs distribution, wicket chance, and delivery paths. Explain that the field does not alter simulation probabilities.
7. Reveal the scripted next over. Compare choices without treating the scripted bowler as an answer key. Inspect the transparent captaincy scoring rubric.
8. Restart or move to the next challenge. Toggle light mode and demonstrate field placement at a narrow mobile width.
